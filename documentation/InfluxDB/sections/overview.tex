\section{Overview}
This document describes the design of the InfluxDB historian component within the distributed microgrid telemetry system. The historian is responsible for receiving time-series electrical measurements from distributed DAQ nodes, persisting them with nanosecond-precision timestamps derived from PTP-synchronised STM32 firmware, and exposing them for downstream query and analysis.

Version 2 of this document records the historian as built. Where the implementation departed from the original design, the as-built behaviour is described, and design elements that were not implemented are listed as deferred in the relevant section.
