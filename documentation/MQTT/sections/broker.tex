\section{Broker Selection \& Configuration}

Eclipse Mosquitto is selected as the MQTT broker. This is suitable of a research testbed with two DAQ nodes as it is:
\begin{itemize}[noitemsep]
  \item lightweight
  \item well documented
  \item suitable for co-deployment on the historian server alongside InfluxDB without significant resource contention
  \item carries no licensing contraintes under the eclipse public licence 
\end{itemize}
Alternatives such as EMQX and HiveMQ were considered but are designed for large-scale deployments with thousands of concurrent clients; the additional operational complexity is not justified at this scale.

The broker runs on the microgrid historian server, bound to the lab LAN interface. Key configuration parameters are as follows:

\begin{lstlisting}[language=toml]
listener 1883 <lab_lan_ip>
allow_anonymous false
password_file /etc/mosquitto/passwd

persistence true
persistence_location /var/lib/mosquitto/

max_inflight_messages 100
max_queued_messages   1000

log_type error
log_type warning
log_type notice
\end{lstlisting}  

Port 1884 is used for internal lab LAN traffic. TLS on port 8883 is reserved as a future hardening measure and discussed in section X. Persistence is enabled so that QoS 1 messages survive a broker restart without loss. The \texttt{max\_inflight\_messages} and \texttt{max\_queued\_messages} parameters are bounded to prevent unbounded memory growth under a backlogged subscriber.
